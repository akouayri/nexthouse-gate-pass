Firebase Realtime DB Settings

Paste your Firebase credentials below to enable live sync across different devices (e.g. Guest on phone, Guard on tablet).

Quick Firebase Setup (Free Tier):

  1. Go to Firebase Console and click Add Project.
  2. Navigate to Build > Realtime Database and click Create Database.
  3. Under Rules, set read/write permissions to true (or start in Test Mode).
  4. Click Project Settings (Gear icon) > Web App (</>) to copy your web config parameters below.
Production Hosting

Deploy to GitHub Pages (100% Free)

Host your Airbnb Gate Security App live on the internet with a custom public URL.

1

Create a GitHub Repository

Go to github.com/new, name your repository airbnb-gate-pass, keep it Public, and click Create Repository.

2

Upload index.html

In your new repository, click Uploading an existing file, upload this single index.html file, and click Commit Changes.

3

Enable GitHub Pages

Go to Settings > Pages in your repository. Under Branch, select main (or master) and click Save.

4

Copy Your Live URL

Within 1-2 minutes, GitHub will publish your app live at:

https://YOUR-USERNAME.github.io/airbnb-gate-pass/

Once deployed, paste your live URL into the Host Link Generator tab to auto-generate Airbnb chat links!
